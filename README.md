# Returns Portal · 自助退货中心

电商售后全流程演示：用户自助完成退货申请，商家侧动作可模拟，进度时间线实时跟踪。

## 完整流程

```
查订单 → 勾选退货商品（可选退货数量）→ 填原因/描述/退款方式 → 提交
  → 商家审核（通过/拒绝分支）→ 用户填写寄回物流 → 商家收货验收 → 退款完成
```

## 功能

- 订单号查询（3 个演示订单一键填充）
- 部分退货：支持单品、选数量（退几件）
- 退货原因 7 类 + 自定义描述 + 退款方式（原路/余额）
- **售后状态机**：`applied → approved → shipped → received → refunded`，
  含 `rejected` 拒绝分支，非法流转被禁止
- 时间线可视化：完成 / 进行中 / 未到达三态 + 每步时间戳与备注
- 寄回物流回填（快递公司 + 运单号）
- 我的售后记录列表（localStorage 持久化，可回看任一单）
- 演示模式：一键模拟商家审核/收货/退款动作

## 运行

浏览器直接打开 `index.html`。
